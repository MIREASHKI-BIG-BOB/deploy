# 🚀 CTG System - Полная инструкция по запуску

## 🪟 **Для Windows**

### **Одна команда запускает ВСЮ систему:**
```cmd
cd deploy/deploy
start.bat up-d
```

### **Команды управления (Windows):**
```cmd
start.bat          # Показать справку
start.bat build    # Собрать Docker образы  
start.bat up-d     # Запустить в фоне (РЕКОМЕНДУЕТСЯ)
start.bat down     # Остановить систему
start.bat ps       # Статус всех сервисов
start.bat logs     # Логи всех сервисов
start.bat rebuild  # Пересобрать всё заново
```

---

## **Для macOS/Linux**

### **Одна команда запускает ВСЮ систему:**
```bash
cd deploy
make up-d
```

### **Команды управления (Mac/Linux):**
```bash
make               # Показать справку
make build         # Собрать Docker образы  
make up-d          # Запустить в фоне (РЕКОМЕНДУЕТСЯ)
make down          # Остановить систему
make ps            # Статус всех сервисов
make logs          # Логи всех сервисов
make rebuild       # Пересобрать всё заново
```

---

## **Что нового в системе**


### ** Реальные медицинские данные:**
- **FHR**: < 90 или > 180 уд/мин → Красные зоны
- **UC**: > 65 мм рт.ст → Гипертонус 
- **Spasms**: > 70 → Критические судороги
- **Real-time ML**: Живые предсказания гипоксии

---

## **Автоматизация (работает на всех платформах)**

1. Все сервисы запускаются в правильном порядке
2. Health checks ждут готовности каждого
3. Генератор активируется автоматически (/api/on)
4. Данные сразу начинают передаваться
5. ML анализ включается сам
6. Аномалии детектируются в реальном времени

---

## 📱 **Доступ к системе**
- **Главная**: http://localhost:3000
- **CTG мониторинг**: http://localhost:3000/ctg  
- **Данные**: Автоматически поступают через ~30 секунд

```cmd
start.bat rebuild  # Перезапуск
```

